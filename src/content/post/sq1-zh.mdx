Square-1 有 8 个占 60° 的角块和 8 个占 30° 的棱块。切层会让角棱在上下层之间移动，所以打乱后两层可以有不同的块数，外形也会变化。本文使用 Basic Lars 入门路线：先恢复正方体形状，再分开上下层颜色，最后排列角棱。

## 记号与读图

让中层前方的短边在左侧，左手握住这一半。上层称 U，下层称 D。图中 U 在左、D 在右，**两层都从上方看**；D 图相当于透过上层观察下层。

| 记号 | 操作 |
| --- | --- |
| `(a,b)` | U 转动 a 个 30°，D 转动 b 个 30° |
| 正数、负数 | U 的正向从上方看为顺时针；D 的正向从底部看为顺时针，因此在本文的 D 图中为逆时针 |
| `/` | 右半边切层转动 180°；执行前，上下层的切口都要与中层切口对齐 |
| `U`、`D` | `(3,0)`、`(0,3)`，即对应层转 90° |
| `'`、`2` | 反向、转动两次，例如 `U' = (-3,0)`，`U2 = (6,0)` |
| `M2` | 本文的组合手法：`(1,0) / (-1,-1) / (0,1)` |

各阶段允许在执行公式前转动 U、D 来匹配图示；公式开始后保持握持方向。

## 1. 复形：先做六角星

入门时先把 8 个角块中的 **6 个**放到底层，组成没有棱块间隔的六角星；剩下 2 个角块和全部 8 个棱块在上层。

收集角块时，先把已有的一段连续角块留在底层切口左侧，让这一段的一端贴着切口。转动上层，让待加入的角块落在右半边，并在切层后接到这一端；用 `/` 接入后，调整 D，把增长后的角块段重新留在左侧。重复这个过程，先拼出 3 个连续角块，把它们转到底层左半边保存；接下来只转 U 和右半边切层，在上层收集另一组 3 个角块。用一次切层将两组接到底层，底层就成为六角星。

底层形成六角星后，只看上层两个角块之间的棱块数量来识别。沿圆周数两条间隔，可能是 4+4、3+5、2+6、1+7 或 0+8。转动 U、D，让两个角块和切口的方向与对应图片一致，再执行公式。

## 2. 角块分色

选定顶色与底色，本文配图使用黄顶白底。先让四个顶色角块都进入 U、四个底色角块都进入 D；侧面颜色留到角块排列时处理。

先数每层的异色角块。每层各有一个时，转动 U、D 匹配第一张图，使用单角换层；每层各有两个时，把它们并排放到图示半层，使用第二条公式。异色角更多时，先交换一组，再重新识别。黄色与白色标出当前的角块分布，灰色棱块暂不参与识别。
